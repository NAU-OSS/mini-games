# Mini-games
open-source repository dedicated to the containment of multiple mini games written in C. 
---
## overview 
current games contained :

- tick tack toe
- flip a coin
- rock paper scissors
---
# Getting started 
### Prerequisites 
c compiler must be installed 

optional download: make 

eg. Lunux c compiler installation 
```
sudo apt update && sudo apt install build-essential
```
verify installation with ```gcc --version``` or ```clang --version```

### cloning the repository 
```
git clone https://github.com/NAU-OSS/mini-games
# Access the games folder 
cd games 
```
### Compile Games 
eg. rock, paper, scissors
```
# compile
 gcc rockPaperScissors.c - o rpsGame
# run
./rpsGame
```

### Quick Notes 
if you have `make` installed you can build all the games at once by executing these commands: 
```
# build all mini games
make
# run the game you want
./bin/rockPaperScissors
```
